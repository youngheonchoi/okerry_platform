# TASK 004. 접속 가능 컨텐츠 리스트 화면 구현


## 목적

로그인 완료 후 해당 사용자가 접근 가능한 서비스 목록을 확인하고 선택할 수 있는 화면을 구현한다.


## 구현 범위

* 로그인 성공 후 진입하는 서비스 리스트 화면을 추가한다.
* 상단에 `이름님 환영합니다.` 문구를 표시한다.
* 상단에 로그아웃 버튼을 제공한다.
* 사용자가 접근 가능한 서비스를 카드 형태로 표시한다.
* 접근 가능 서비스 영역은 화면의 남는 높이를 최대한 사용하고, 페이지 전체가 아니라 해당 영역 내부에서만 카드 목록이 스크롤되도록 구성한다.
* 서비스 카드 수가 많아져도 카드 높이가 압축되지 않고, 넘치는 목록만 내부 스크롤로 처리되도록 유지한다.
* 서비스 이름, 서비스 설명, 서비스 이동에 필요한 기본 정보가 카드에 드러나도록 구성한다.
* 공통 UI는 Okerry UI 클래스와 CSS 변수를 우선 사용하고, 필요한 경우에만 `platform_style.css`에 프로젝트 전용 스타일을 추가한다.
* 화면 렌더링과 주요 UI 요소 노출 여부를 확인할 수 있는 테스트 또는 검증 항목을 반영한다.


## 제외 범위

* 실제 OAuth2/OIDC 인가 요청 시작 로직 변경
* 서비스별 권한 정책 설계 변경
* 서비스별 상세 프로필 정보 관리 기능 추가
* 서비스 목록 데이터의 최종 운영 관리 화면 구현
* 카드 클릭 이후 각 서비스 내부 기능 구현
