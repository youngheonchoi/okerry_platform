# DASHBOARD.md

프로젝트 작업 현황을 관리하는 대시보드입니다.
에이전트는 작업 요청을 받으면 이 파일에서 작업 번호와 상태를 확인한 뒤, 연결된 상세 작업 파일을 읽고 작업을 진행합니다.



## 작업 진행 규칙

1. 사용자가 “N번 작업 진행해줘”라고 요청하면 `작업 목록`에서 N번 작업을 찾는다.
2. 해당 작업의 `상세 파일`을 먼저 읽는다.
3. 상세 파일의 요구사항, 수정 대상, 완료 조건을 기준으로 작업한다.
4. 작업 상태가 `[진행중]`이면 상세 파일의 진행 로그를 확인한 뒤 이어서 작업한다.
5. 에이전트는 작업 진행 중 필요한 경우 `진행중` 상태까지만 갱신한다.
6. `완료` 상태 변경은 사용자만 수행한다.
7. 완료된 작업은 [완료], 진행 중인 작업은 [진행중], 아직 시작하지 않은 작업은 [미완료]로 표시한다.

## 작업 진행 규칙

1. 사용자가 “N번 작업 진행해줘”라고 요청하면 `작업 목록`에서 N번 작업을 찾는다.
2. 해당 작업의 `상세 파일`을 먼저 읽는다.
3. 상세 파일의 요구사항, 수정 대상, 완료 조건을 기준으로 작업한다.
4. 작업 상태가 `[진행중]`이면 상세 파일의 `진행 로그`, `작업 체크리스트`, `완료 조건`을 확인한 뒤 이어서 작업한다.
5. 작업을 진행한 뒤에는 상세 파일의 `진행 로그`에 수행한 내용을 기록한다.
6. 작업 중 일부 또는 전부를 진행하면 상세 파일의 `작업 체크리스트`와 `진행 로그`를 갱신하고, DASHBOARD 작업 상태는 필요 시 `[진행중]`으로 변경한다.
7. 에이전트는 완료 조건 충족 여부를 상세 파일에 기록할 수 있지만, DASHBOARD 작업 상태를 `[완료]`로 변경하지 않는다.
8. DASHBOARD의 `[완료]` 상태 변경은 사용자만 수행한다.
9. 완료된 작업은 `[완료]`, 진행 중인 작업은 `[진행중]`, 아직 시작하지 않은 작업은 `[미완료]`로 표시한다.




## 상태 정의

| 상태 | 의미 |
|---|---|
| 미완료 | 아직 작업하지 않음 |
| 진행중 | 현재 작업 중 |
| 완료 | 구현 및 확인 완료 |
