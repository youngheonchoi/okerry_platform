# TASK 003. 로그인, 회원가입 화면 개선


## 목적

okerry platform의 로그인 화면과 회원가입 화면 UI/UX를 개선한다.


## 구현 범위

* 로그인 화면 개선
* 회원가입 화면 개선
* 로그인과 회원가입 화면의 공통 레이아웃, 문구, 스타일 정리
* 모든 페이지 오른쪽 하단에 라이트 모드와 다크 모드를 전환할 수 있는 버튼 추가
* 기본 테마는 라이트 모드로 적용
* 로그인 페이지 회원가입 영역 하단에 아이디 또는 비밀번호를 모를 경우 관리자에게 문의해야 한다는 안내 문구 추가
* 회원가입 페이지에 이메일 입력 필드와 인증 버튼 추가
* 인증 버튼 클릭 이후 노출되는 인증번호 입력칸과 확인 버튼 추가
* 필요한 경우 Okerry UI 클래스와 CSS 변수 우선 적용
* 화면 개선 결과를 확인할 수 있는 테스트 또는 검증 반영


## 제외 범위

* 실제 로그인 인증 처리 변경
* 회원가입 정보 저장 및 계정 생성 로직 변경
* OAuth2/OIDC Authorization Flow 변경
* 서비스별 비즈니스 정보 수집 기능 추가

* `./gradlew test --no-daemon` 실행 통과를 확인함.

### 2026-07-01

* 브라우저에서 테마 버튼이 동작하지 않는 문제를 확인하고 원인을 재점검함.
* `/js/platform_theme.js`가 Spring Security에서 인증 없이 접근되지 않아 로그인 페이지로 리다이렉트되던 문제를 확인함.
* 보안 설정에 `/js/**` 정적 리소스 허용 경로를 추가함.

* `html`과 `body` 모두에 라이트 모드 초기값을 적용하고, DOM 로드 이후 버튼 이벤트를 바인딩하도록 스크립트를 정리함.
* 정적 JS 리소스 서빙 검증 테스트를 추가하고 `./gradlew test --no-daemon` 재실행 통과를 확인함.
